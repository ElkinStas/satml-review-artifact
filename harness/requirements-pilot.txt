# ============================================================================
# PINNED analysis + SDK stack for the rerag-re image.
#
# WHY: an unpinned name ("angr") makes pip install whatever is latest AT BUILD
# TIME, so every rebuild can produce a different image digest and a different
# disassembler. That is what happened across three rebuilds here (angr 9.3.0 /
# 9.3.2 / 9.3.3). Pinning is what makes `docker build` reproducible.
#
# IMPORTANT: capstone is NOT pinned independently -- angr pins it exactly itself
# (angr 9.3.2 requires capstone==5.0.9). Pinning both by hand is how the earlier
# build broke: angr==9.3.2 + capstone==5.0.6 is an unsatisfiable pair.
#
# Versions below are the resolved set for angr 9.3.2, verified with
# `pip install --dry-run`. To move a version: change it here, rebuild, then
# `python -m agent.pin_environment --regenerate`.
# ============================================================================
